# 🌾 KisanMitra

### Smart Crop Advisory & Farmer Assistance Platform

KisanMitra is a full-stack web application designed to provide farmers with useful agricultural information in one place. It combines crop advisory, weather information, market information, and farmer-focused services through a simple multilingual interface.

## 🚀 Live Demo

👉 https://kisanmitra-ylvw.onrender.com/

## ✨ Key Features

- 🌱 **Crop Advisory** – Get crop-related recommendations and guidance.
- 🌦️ **Weather Information** – Access weather information useful for farming decisions.
- 📈 **Market Information** – View agricultural market-related information.
- 💧 **Irrigation Guidance** – Support for irrigation-related decisions.
- 🐛 **Pest & Disease Assistance** – Information to help identify and manage crop problems.
- 🧪 **Soil Health Support** – Farmer-focused soil-related guidance.
- 📅 **Crop Planning** – Helpful information for crop planning and management.
- 🌐 **Multilingual Interface** – Designed to support multiple Indian languages.
- 👤 **User Authentication** – Registration and login functionality.
- 📱 **Responsive Design** – Designed to work across desktop and mobile devices.
